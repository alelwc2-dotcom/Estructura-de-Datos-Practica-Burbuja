# Algoritmo de Ordenamiento por Burbuja en Java

Implementación en Java del método de ordenamiento interno **Burbuja (Bubble Sort)** optimizado con bandera booleana para detectar arreglos ordenados en complejidad `O(n)` en el mejor caso.

**Asignatura:** AED-1026 Estructura de Datos (Unidad 5)  
**Institución:** Instituto Tecnológico Superior de Xalapa

## Archivos del proyecto
- `Burbuja.java`: Contiene el método `ordenar(int[] arr)` y el método auxiliar `imprimirArreglo(int[] arr)`.
- `Mainburbuja.java`: Clase principal con el método `main` para probar el ordenamiento sobre el arreglo `{6, 1, 5, 8, 3, 2, 7, 4}`.
